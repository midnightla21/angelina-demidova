# Ангелина Демидова

Персональный сайт хирурга-колопроктолога в Москве. Профессиональный опыт, подход к лечению и запись через официальные страницы клиник.

**[Открыть сайт → angelina-demidova.ru](https://angelina-demidova.ru/)**

## Особенности

- Шесть языков: русский, английский, узбекский, таджикский, вьетнамский и китайский.
- Плёночный портрет и непрерывная типографическая анимация. Полноразмерная маска перекрытия проводит текст за фигурой, сохраняя детали её контура.
- Адаптивная компоновка, управление движением, навигация с клавиатуры и поддержка `prefers-reduced-motion`.
- Отдельные адреса языковых версий, серверный HTML, локализованные метаданные, canonical, hreflang и sitemap.
- Статическая публикация на VPS через Caddy с HTTPS. Постоянно работающий Node.js на сервере сайта не требуется.

## Технологии

React 19 · TypeScript · Vinext / Vite · Tailwind CSS 4 · Base UI / shadcn · Caddy

Сайт создан при участии Никиты Демидова, Ангелины Демидовой и Codex. Медицинские сведения согласованы с Ангелиной. Дизайн развивает выбранный референс MotionSites.

## Локальный запуск

Требуется Node.js **22.13 или новее** и npm. Версии зависимостей закреплены в `package-lock.json`.

```sh
npm ci
cp .openai/hosting.example.json .openai/hosting.json
npm run dev
```

Откройте адрес, который напечатает сервер. Файл `hosting.json` нужен инструментам сборки; пример не содержит привязки к чужому аккаунту и подходит для локальной работы.

## Сборка и проверки

```sh
npm run build
npm run start -- --port 3001
```

Во втором терминале:

```sh
node --test tests/locales.test.mjs
```

Проверки охватывают шесть переводов, маршруты, поисковые метаданные, ссылки записи, маску портрета, sitemap, редирект `/ru` и ответ 404. Для другого адреса задайте `SITE_TEST_ORIGIN`.

## Статическая публикация

После сборки оставьте локальный production-сервер на порту 3001 запущенным и выполните:

```sh
node scripts/export-vps.mjs
```

Экспортёр сохраняет HTML, React payload и соответствующие им клиентские файлы в `outputs/vps-…/public`, а рядом создаёт конфигурацию Caddy и описание версии. Сборка и работающий сервер должны соответствовать одному состоянию исходников. Перед экспортом изменения должны быть закоммичены.

Порядок размещения описан в [docs/deployment.md](docs/deployment.md). Публикация исходников на GitHub сама по себе не обновляет работающий сайт.
